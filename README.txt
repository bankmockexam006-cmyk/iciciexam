BUZZIELS World Class Assessment 2026 — Website

FILES
- index.html: candidate login, instructions, exam and result screens
- style.css: responsive styling
- app.js: schedule, timer, answer handling and scoring
- questions.js: all 100 questions, four options and answer key

EXAM SCHEDULE
- Date: 21 November 2026
- Start: 12:15 PM IST
- Expiry: 1:30 PM IST
- Duration: 75 minutes (the schedule requested for this website)
- Scoring: +1 correct, -0.25 incorrect, 0 unanswered
- Pass mark: 70 net marks

HOW TO RUN
1. Extract the ZIP file.
2. Keep all four files in the same folder.
3. Open index.html in Chrome, Edge or Firefox.
4. For hosting, upload the four files to the same GitHub Pages repository/folder.

IMPORTANT LIMITATIONS
This is a front-end-only HTML/CSS/JavaScript project. The schedule is checked using the candidate device's clock and browser JavaScript; it is NOT server-time controlled and can be bypassed by changing the device clock or browser storage. Results are calculated and shown in the same browser only. There is no central examiner dashboard, email delivery, or tamper-proof result storage. For a secure live examination, server-side time validation and server-side answer storage are required.

SOURCE PDF QUALITY-CONTROL ADJUSTMENTS
The question paper and examiner answer key were extracted from BUZZIELS_World_Class_Assessment_2026.pdf. The PDF itself flags some items:
- Q11: both options A and C satisfy the printed seating conditions; both are accepted.
- Q17: all four printed options are identical; any selected option is accepted.
- Q33: Q2, Q3 and Q4 tie at 30% profit margin; B, C and D are accepted.
- Q100: the answer key says the correct input is 16, but the PDF options omit 16; option D was changed from 15 to 16 and D is keyed.
Other questions/options follow the uploaded PDF. Review these corrections before a live sitting.
